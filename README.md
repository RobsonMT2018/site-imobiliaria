# 🏠 Robson MT Imóveis - Landing Page Imobiliária (Sorocaba e Região)

Uma landing page moderna, elegante e otimizada para captação de clientes interessados em compra, venda e consultoria de imóveis residenciais (casas e apartamentos) em Sorocaba e região.

O projeto conta com um visual refinado e botões estratégicos de **Call to Action (CTA)** focados no atendimento direto via WhatsApp.

---

## 🚀 Funcionalidades

* **Design Responsivo & Elegante:** Ajuste perfeito para smartphones, tablets e desktops.
* **CTAs Diretos via WhatsApp:** Botões com links pré-formatados para o WhatsApp do corretor (`(15) 99888-3175`).
* **Seção Sobre Mim & Apresentação:** Espaço dedicado para construir autoridade e gerar confiança com potenciais clientes.
* **Exibição de Serviços e Etapas:** Exposição clara do fluxo de trabalho (Entendimento, Busca e Acompanhamento).
* **Menu Interativo:** Menu de navegação responsivo com toggle para telas menores e scroll suave pelas seções.
* **Botão Flutuante do WhatsApp:** Ícone fixo no canto da tela para acesso rápido em qualquer momento da navegação.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico:** Boa estrutura para SEO e acessibilidade.
* **CSS3 nativo (com variáveis CSS):** Estilização personalizada, paleta de cores consistente e sem dependências pesadas de frameworks externos.
* **JavaScript Vanilla:** Lógica simples e leve para o controle do menu mobile e atualização do ano automático no rodapé.
* **Google Fonts:** Tipografias *Manrope* e *DM Sans* para uma leitura agradável e moderna.

## 🌐 Como Publicar no GitHub Pages

Para publicar este projeto gratuitamente e disponibilizar o link público:

1. **Renomeie o arquivo principal:**
   * Certifique-se de que o arquivo da landing page se chame **`index.html`** no seu repositório (o GitHub Pages necessita deste nome para reconhecer a página principal).

2. **Crie o repositório no GitHub:**
   * Vá em seu perfil no GitHub e crie um novo repositório (ex: `robson-mt-imoveis`).
   * Adicione o arquivo `index.html` e o arquivo `README.md`.

3. **Ative o GitHub Pages:**
   * No seu repositório, vá na aba **Settings** (Configurações).
   * No menu lateral esquerdo, clique em **Pages**.
   * Em **Build and deployment** -> **Branch**, selecione `main` (ou `master`) e a pasta `/ (root)`.
   * Clique em **Save**.
   * Aguarde alguns instantes e o seu site estará no ar no link gerado pelo GitHub!
